Why Learn CSS?

CSS (Cascading Style Sheets) is used to design and style webpages. It controls colors, layouts, spacing, animations, responsiveness, and user interaction. CSS makes websites attractive and user-friendly.

1. CSS Selectors

What is it?

Selectors are used to target HTML elements and apply styles.

Why is it used?

To apply specific styles to specific elements.

Where is it used?

Buttons, headings, forms, navigation bars, cards and every webpage component.

2. CSS Box Model

What is it?

Every HTML element is treated as a box containing Content, Padding, Border and Margin.

Why is it used?

To create spacing and proper layout structure.

Favicon

A favicon (Favorite Icon) is the small image displayed in the browser tab next to the webpage title. It helps users easily identify a website among multiple open tabs and improves brand recognition.

Why is it Used?

Favicons make websites look professional, improve user experience, and help visitors quickly locate a webpage.

Where is it Used?

Favicons are used in browser tabs, bookmarks, browser history, and mobile home screen shortcuts.

Example

The favicon is added inside the HTML <head> section using the <link rel="icon"> tag.

<link rel="icon" type="image/png" href="favicon.png">

6. Position Property

Position decides where an element appears on the webpage.

  • Static → Default Position
  • Relative → Moves from Original Position
  • Absolute → Moves Relative to Parent
  • Fixed → Stays on Screen
  • Sticky → Sticks While Scrolling
