JavaScript Variables (Easy Learning)

1. What is a Variable?

A variable is a container used to store data values.

let name = "Samjana"; console.log(name);

2. Declaration

Declaration means creating a variable name.

let age;

3. Initialization

Initialization means assigning a value.

let age; age = 20; console.log(age);

4. var, let, const

var → old method

let → can change value

const → cannot change value

var city = "Chennai"; let marks = 90; const country = "India";

5. JavaScript Engine

JavaScript runs using engines like V8, SpiderMonkey, JavaScriptCore.

console.log("V8 - Chrome"); console.log("SpiderMonkey - Firefox"); console.log("JavaScriptCore - Safari");

6. Printing Statements

Used to display output.

console.log("Hello World"); alert("Welcome"); document.write("JS Learning");
