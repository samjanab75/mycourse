HTML, DOM, React, Components & Functions

1. What is DOM?

DOM stands for Document Object Model. It represents an HTML document as objects. JavaScript uses DOM to access, change, add, or remove HTML elements dynamically.

Hello DOM

2. What is Function?

A Function is a reusable block of code that performs a specific task.

3. What is React?

React is a JavaScript library developed by Meta. It is used to build fast, interactive and reusable User Interfaces (UI).

React Features

  • Component Based
  • Virtual DOM
  • Reusable Code
  • Fast Rendering
  • Single Page Application

4. What are Components?

Components are reusable pieces of UI in React. Instead of writing the same code again, we create a component once and use it many times.

Types of Components

  • Functional Component
  • Class Component

5. JavaScript Function Types

Normal Function

function greet(){
   alert("Hello");
}

Function Expression

const greet = function(){
   alert("Hello");
}

Arrow Function

const greet = () =>{
   alert("Hello");
}

Anonymous Function

setTimeout(function(){
   console.log("Hello");
},1000);

Callback Function

function display(callback){
   callback();
}

display(function(){
   alert("Callback Executed");
});
