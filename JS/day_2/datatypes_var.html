Variables and Data Types in JavaScript

What is a Variable?

A variable is a container used to store data values.

Variable Keywords

  • var - Old way of declaring variables.
  • let - Modern variable declaration.
  • const - Constant value, cannot be reassigned.

Data Types

1. String

let studentName = "Samjana";
console.log(studentName);

2. Number

let age = 20;
console.log(age);

3. Boolean

let isStudent = true;
console.log(isStudent);

4. Undefined

let address;
console.log(address);

5. Null

let marks = null;
console.log(marks);

6. BigInt

let population = 12345678901234567890n;
console.log(population);

7. Symbol

let uniqueId = Symbol("id");
console.log(uniqueId);

Easy Memory Trick

SNBUNBS

  • S → String
  • N → Number
  • B → Boolean
  • U → Undefined
  • N → Null
  • B → BigInt
  • S → Symbol
