JavaScript Primitive Data Types

  • String → Text values ("Hello", "Samjana")
  • Number → Numeric values (10, 99.5)
  • Boolean → true or false
  • Undefined → Variable declared but not assigned a value
  • Null → Intentional empty value
  • BigInt → Large integers (12345678901234567890n)
  • Symbol → Unique identifier (Symbol("id"))

Easy Memory Trick

S N B U N B S

  1. S → String
  2. N → Number
  3. B → Boolean
  4. U → Undefined
  5. N → Null
  6. B → BigInt
  7. S → Symbol

Examples

String    : "Hello"
Number    : 100
Boolean   : true
Undefined : undefined
Null      : null
BigInt    : 123456789n
Symbol    : Symbol("id")
