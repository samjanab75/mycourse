JavaScript const Keyword

Definition

const is used to declare a variable whose value cannot be reassigned after initialization.

Rules of const

  1. Must be initialized during declaration.
  2. Cannot be reassigned.
  3. Block scoped.
  4. Used for fixed values.

Syntax

const variableName = value;

Correct Example

const studentName = "Samjana";
console.log(studentName);

Incorrect Example

const age;
console.log(age);

// Error:
// Missing initializer in const declaration

Cannot Reassign

const city = "Chennai";

city = "Mumbai"; // Error

Easy Memory Trick

CONST = Constant Value

  • C → Create
  • O → Once
  • N → No Reassignment
  • S → Same Value
  • T → Throughout Program

Comparison

Keyword Can Reassign? Initialization Required?
var Yes No
let Yes No
const No Yes
