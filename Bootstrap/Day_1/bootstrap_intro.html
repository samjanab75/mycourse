What is Bootstrap?

Bootstrap is a free and open-source front-end framework used to create responsive and mobile-friendly websites. It provides ready-made CSS classes and JavaScript components that help developers build attractive websites quickly.

Bootstrap was originally developed by Twitter and is now one of the most popular frameworks in web development. It reduces coding effort and provides professional website designs.

Why Use Bootstrap?

  • Creates Responsive Websites
  • Easy to Learn
  • Faster Development
  • Mobile First Design
  • Cross Browser Support
  • Professional Components
  • Large Community Support

Important Bootstrap Classes

Class Description
.container Creates responsive container.
.row Creates rows in grid layout.
.col-md-6 Creates responsive columns.
.btn Creates buttons.
.card Creates card component.
.navbar Creates navigation bar.
.text-center Centers text.
.bg-primary Adds background color.
.shadow Adds shadow effect.
.rounded Adds rounded corners.
.d-flex Creates flex layout.
.m-3 Adds margin spacing.
.p-3 Adds padding spacing.
